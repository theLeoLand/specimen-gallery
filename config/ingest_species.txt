# config/ingest_species.txt
#
# Species pool for `bin/ingest --batch` (and the future scheduled job).
# One scientific name per line. Lines starting with # and blank lines are ignored.
#
# Each batch run finishes species that have never been imported before it repeats
# any. Only after every name on this list has at least one specimen do we circle
# back, and then we take the ones with the fewest imports. The same iNat photo
# or observation is never uploaded twice.
# The list is intentionally broad and skewed toward species that (a) have lots of
# research-grade CC0 photos on iNaturalist and (b) make clean single-subject
# cutouts (bold, high-contrast subjects). Add/remove freely.
